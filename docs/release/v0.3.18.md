## Highlights
- **執行 / 審核 AI 的規則收緊,從源頭少踩「工作悄悄不見」** — 執行 AI 被明確要求只在自己的工作區內動手、不准跑去主專案、產出要進得了 git;審核 AI 被要求以實際改動為準(不只信回報),工作區根本沒改動就直接判失敗。

## Fix
把這幾版踩到的坑寫成 AI 的硬規則：執行 AI —— 只在 worktree 內改+驗、不准 cd 出去或改主專案、交付物必須 git 追蹤得到(別落在 .gitignore)、只動 ticket 相關檔；審核 AI —— summary 只當參考一律看實際 diff、工作區沒有任何未提交改動就一律判失敗。順手移除沒用的 prompt 雜訊（每次跑省一點 token）。
