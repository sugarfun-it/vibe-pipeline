## Backend EADDRINUSE fallback

`server/index.ts` `Bun.serve` 包 try/catch,`EADDRINUSE` 改 `port: 0` 讓 OS 派閒置 port。bind 後寫 `~/.vibe-pipeline/server.json`(merge `repo_path` / `log_path`,蓋 `pid` / `port` / `started_at`)。

`cli/lib/serverBase.ts` `serverPort()` fallback chain:`VBPL_SERVER_PORT` env > `server.json` > 3001。

PWA `src/api/_client.ts` 走 relative URL,跟 PWA 同 origin,不在乎 port。

Tailscale 由 user 自管 — port 換了之後:

```bash
tailscale serve --bg --https=443 http://localhost:<actual-port>
```

`<actual-port>` 從 `~/.vibe-pipeline/server.json` 拿。

## 升級

```bash
vbpl update
# 或 PWA Settings → 「套用更新」
```

若 prod backend 卡 orphan socket 撞 `EADDRINUSE` 升級失敗,先重開機或 `Restart-NetAdapter -Name "*" -Confirm:$false`(Win admin)。升完後 backend 自動 fallback,不再 crash。
