## port 換掉後 Tailscale 怎麼辦

backend 實際用的 port 寫在 `~/.vibe-pipeline/server.json`。Tailscale forward 要重新指過去:

```bash
tailscale serve --bg --https=443 http://localhost:<server.json 內的 port>
```

PWA / CLI 都自己讀 `server.json`,不用改。

## 升級

```bash
vbpl update
# 或 PWA Settings → 「套用更新」
```

升級時若卡 `EADDRINUSE`(舊 port 還在),重開機或 `Restart-NetAdapter -Name "*" -Confirm:$false`(Win admin)。升完 backend 會自動換 port,不再 crash。
