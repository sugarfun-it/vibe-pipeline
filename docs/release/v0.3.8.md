## Highlights
- **更新後不會再卡在「連不上、得手動清才能用」** — 舊版更新時殘留的背景小程式有時會霸佔原本的網址埠（3001），害新後端只能退到別的埠、遠端就連不到。現在後端啟動時會自己清掉這些殘留、搶回 3001，更新流程也會在換版前先把它們收乾淨。

## Fix
後端在跑 ticket 時會開一些背景預覽程式；在 Windows 上它們可能在後端被換掉後沒跟著結束，繼續佔著原本的埠，導致新後端只能換埠、外部網址就失效。現在兩道防線：後端啟動撞到埠被佔時會先清掉這些殘留再搶回原埠；更新程式換版前也會一併收掉。兩者都只動更新自己開的背景程式，不碰你專案本身的開發伺服器。

vbpl update
