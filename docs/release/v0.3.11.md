## Highlights
- **更新視窗不再卡著等後端,裝完就關** — 之前安裝程式會在「啟動後端」那步一直 ping 後端等它回應,但後端冷啟動每次都超過那個等待時間,所以視窗每次都卡滿才關、還洗一堆失敗訊息。現在啟動後端後直接收工關窗,後端在背景自己起來(狀態看 App 就好)。

## Fix
安裝最後一步會輪詢後端健康檢查才肯結束,而後端在 Windows 上是雙層冷啟動、時間穩定超過輪詢上限,於是視窗每次都卡到逾時。改成：把後端交給背景的啟動程序（它本來就會自己等到好、而且安裝程式關掉也不影響它），安裝程式啟動後就直接結束，不再空等。

（注意：這次更新跑的還是舊版安裝程式、視窗仍會卡約 20 秒;裝上 v0.3.11 之後才生效。）

## 升級
```bash
vbpl update
# 或 PWA Settings → 「套用更新」
```
