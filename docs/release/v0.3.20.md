## Highlights（彙整 v0.3.1 ~ v0.3.20）
- **更新流程整套修好** — 更新後不再黑屏(偵測到載不起來會自己清快取重載)、安裝視窗裝完就關不再卡、版本查詢偶爾抽風也照樣抓得到最新版。
- **pipeline 不再悄悄漏掉一張 ticket 的成果** — worktree 建立時自動帶齊 `.env` 等設定檔、執行 AI 被約束只在自己的工作區動手、真的沒產出會明確停下而不是假裝完成。
- **多 ticket pipeline 收尾多一道整合檢查** — 抓「兩張各自都過、合起來卻對不上」的問題(例如前後端參數漏帶),發現就暫停讓你修。
- **執行 AI 沒做到目標不會自己收手** — 用內建 `/goal` 把「目標達成前不要停」變成硬性條件。
- **雜項** — 新增「刪除已合併 pipeline」一鍵清列表;ticket 失敗原因講得更清楚(如登入過期 401);`vbpl run --wait` 對新 pipeline 不再卡住不動;審核通過不再被誤判成失敗。

## 升級
```bash
vbpl update
# 或 PWA Settings → 「套用更新」
```
