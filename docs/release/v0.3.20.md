## Highlights
- **修掉「審核明明通過卻被當失敗、害 pipeline 假暫停」** — 審核 AI 照指示把結論寫成 `verdict:PASS` 時,之前沒認得這個前綴、被當成失敗,導致整條 pipeline 通過了卻暫停。現在 `verdict:` 前綴會正確識別。

## Fix
verdict 解析只認開頭是 `PASS`/`FAIL` 的那行,但 AI 常照字面回 `verdict:PASS` → 開頭是 `v` → 被誤判為失敗 → 整合檢查假性不過、pipeline 假暫停。修正：解析時容忍 `verdict:`（含全形冒號）前綴;同時把整合審核的指示改成只回單一個詞、別加前綴。對所有審核(單張 ticket / 整合 / 合併)都生效。

升級後，被這個誤判暫停的 pipeline 按「繼續」就會正常通過。
