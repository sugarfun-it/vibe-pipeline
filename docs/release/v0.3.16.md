## Highlights
- **worktree 自動帶設定檔時，更不可能誤搬 `node_modules` 這類大目錄** — 加了第二層保險：就算某個專案的 `.gitignore` 把 `node_modules` 設得不乾淨，漏網的零星檔也會被擋下，絕不會把那種大目錄搬進 worktree。

## Fix
v0.3.14 的「worktree 自動鏡像 gitignored 設定檔」靠「跳過被忽略的整個資料夾」來避開 `node_modules` / `dist`。再補一道 segment 比對當保險，涵蓋極少數 `.gitignore` 設不乾淨、零星檔漏網的情況。純防護性，正常專案行為不變。
