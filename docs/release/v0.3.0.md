## Breaking — Self-update 改 install-script-only

v0.2.x 的 versioned + swap-on-start + `.pending` hook 砍掉,改成 install script 一條 path 自包含 install + update。

**Update 動作改變**:
- PWA Settings「更新」tab **不再有「一鍵更新」按鈕**,改顯版本 + 3 條 copy-paste 指令
- User 在 terminal 跑任一條(`vbpl update` / `irm ... | iex` / `curl ... | sh`)
- install script 自跑 stop backend → download → swap → restart

**為什麼改**:v0.2.x 後端 orchestrate update 要 cross-process 跟 CLI 協作(後端寫 `.pending` 便條 → CLI 撕便條 + swap junction),兩邊邏輯要同步,任一改動就撞。debug 過 9 輪才驗 PASS,但本質脆弱。改 install script 統一入口 = single source of truth,後端只報告版本,UI 只顯示資訊,update 動作交給 install script。

## Add

- **`vbpl update`** subcommand:thin wrapper 跑 install script(local `scripts/install.{ps1,sh}` 優先,fallback GitHub raw)。`--check` 只查不裝,`--json` structured output
- **install.ps1 / install.sh** 加 step 0(自動 stop 既有 backend)+ step 7.2(cleanup 舊版,留 `KeepVersions=2` 個最新)

## Remove

- `server/lib/updater.ts`(全砍)
- `server/lib/installLayout.ts`(全砍)
- `server/routes/system.ts:update` handler(只留 `version`)
- `cli/commands/server.ts:applyPendingUpdateIfAny`(連 import / logic 全砍)
- `src/api/system.ts:triggerSystemUpdate` / `UpdateStarted` type
- `src/features/settings/UpdateTab.tsx` 整檔重寫(從 200 行 polling/apply logic 砍到 ~150 行純顯版本 + copy command)
- 概念整套消失:`.pending` 純文字協作檔、`versions/<tag>.staging/` 中介目錄、swap-on-start hook、後端 self-exit-to-restart

## Fix

- 對齊設計信條「分開工作,不要 cross-process hook」— install script 自包含,沒 `.pending` 便條協作
- 對齊雷 #15「server lifecycle = user-driven first class」— `vbpl server stop/start` 跟 update flow 是同一 mental model
- 對齊信條 6「ground truth 由 backend 驗」— 後端只回 version,不假裝 orchestrate update
