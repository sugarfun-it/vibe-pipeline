## Highlights
- **跑 pipeline 更穩** — 調度改成程式直接帶,不會再卡在「執行中」或狀態對不上;審核還沒判完的那一輪也正確顯「審核中」。
- **執行 / 審核 / 合併 可各自選 provider 跟 model** — Claude、Codex 混搭都行;新 model 出來不用更新 app 就會自己出現在選單。
- **停止 / 繼續 / 當機回復更可靠** — 停了確實停、按繼續從中斷處接、背景跑卡死也救得回,worktree 進度不會掉。

## 這版
把調度從「一個 AI 在帶」換成程式直接做(執行 AI、審核 AI 照舊),更穩也更省;設定頁各角色可分開挑 provider 跟 model;model 清單改從雲端拿,新模型當天就能選。另有多項停止/繼續/合併/通知的穩定性修正。
