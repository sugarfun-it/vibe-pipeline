## Highlights

- **install 不再亂報失敗** — Windows 手動裝完結尾會誤吐 exit 1,看起來像失敗其實沒事,修了
- **PWA 改設定不再壞 project** — 從 PWA 改 `max_parallel` 等 project 設定有時會半 init,救回來
- **Windows CLI 多行輸入** — `vbpl ticket add/update` 加 `--goal-file` / `--prompt-file` / `--acceptance-file <path>`,值給 `-` 走 stdin。繞 cmd shim 對多行字串 escape 不乾淨的雷

## 升級

```bash
vbpl update
# 或 PWA Settings → 「套用更新」
```
