## Fix

### `server/lib/push/tokenStore.ts` 的 `gatewayUrl()` 沒 fallback `DEFAULT_GATEWAY_URL`

v0.2.0 release notes 提到「push gateway `gatewayUrl()` 加 `DEFAULT_GATEWAY_URL` fallback」,但**只修了 `gatewayToken.ts` 跟 `fcm/index.ts`,`tokenStore.ts` 漏修**。

連鎖效應:
- `ensureToken()`(`gatewayToken.ts`)能拿 bearer → `~/.vibe-pipeline/gateway-token` 有寫
- 但 `registerToken()` / `listTokens()` / `postGatewayWithToken()`(`tokenStore.ts`)的 `gatewayUrl()` 回 `null`(因為 `PUSH_GATEWAY_URL` env 沒設)
- `postGatewayWithToken` silent skip("PUSH_GATEWAY_URL 未設定,跳過")→ **device token 從沒寫到 gateway**
- `listTokens` 回 `[]`,所以 `/api/push/tokens` 一直空
- 結局:test push 找不到 target,fanout 死掉,推播全死

修法:`tokenStore.ts` `gatewayUrl()` 對齊另外兩處,沒 env override 就用 `DEFAULT_GATEWAY_URL`。順手砍 `postGatewayWithToken` 內已死的 `if (!url)` 分支。

### `/release <version>` slash command `$1` substitution 沒 work

v0.2.0 加的 `.claude/commands/release.md` 用 `$1` 抓 user 給的 version,實測 Claude Code 沒替換 → bash 收到空字串 → pre-flight fail。改用 `$ARGUMENTS`(整串 user 輸入),內層 `v${RAW#v}` 一樣正規化前綴。
