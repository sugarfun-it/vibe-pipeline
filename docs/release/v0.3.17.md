## Highlights
- **多 ticket 的 pipeline 收尾會多一道「整合檢查」** — 之前每張 ticket 只驗自己,兩張各自過、但兜起來對不上(例如後端要求帶某參數、前端呼叫時漏帶)還是會雙雙過、跑起來才壞。現在所有 ticket 做完、要標「可合併」前，會對整合後的全部改動再審一次跨 ticket 的銜接，發現對不上就暫停讓你修。

## Feature
新增 integration critic：pipeline 全 ticket 完成、轉「可合併」前，對整合後 branch 的完整 diff 跑一次審查，專看跨 ticket 的銜接（API 路徑/參數/型別/契約是否對齊、前後端送收欄位有沒有漏）。發現不一致就暫停並通知，附上是哪兩張 ticket、哪個檔對不上。只在 2 張(含)以上 ticket 時跑；審查程式本身出錯不會卡住 pipeline。
