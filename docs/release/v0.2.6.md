## Highlights

- **Windows 上 ticket / pipeline state 寫檔更穩** — 之前 fs.watch / 防毒密集時 atomic write 偶發 EPERM 衝突而吞失,現在 retry 上限拉長到 4 秒,降到極罕見。

## Fix

底層 atomic file write 在 Windows 上重試窗口從 0.37 秒拉長到 4 秒(exponential backoff)。對 user 來說行為一樣,只是密集 update pipeline / ticket 時不會再偶爾掉資料。

順便:這版包了大量內部結構整理(沒 user-visible 變化),把過去幾個月 grow 起來的大檔拆乾淨,後續維護 / AI agent 改 code 容易很多。
