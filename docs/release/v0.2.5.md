## Highlights

- **修了「立即更新」會卡在「等待 backend 下線」** — 之前 install 跑得太快,Settings 那條 spinner 會一直轉到 3 分鐘 timeout 才報錯。現在偵測到版本變了就直接過。
- **「立即更新」做完不再多顯示一顆「重新整理頁面」按鈕** — PWA 自己會在上方跳「套用更新」橫條,點一下就重新載入,不必兩個按鈕重複問你一樣的事。
- **開源 license 改 MIT** — 之前沒明確開放,現在可以放心 fork / 改 / 商用。

## Fix

升級流程那條 spinner 卡死,是因為舊版 PWA 預期一定會看到「backend 先下線、再上線」這個轉換才會認定升級完成;但 install 跑很快或剛好錯過時機時,PWA 看到 backend 一直在,就一路死等。新版改成只要重啟後回報的版本跟你按下「立即更新」之前不同,就直接收尾。

## 升級

```bash
vbpl update
# 或 PWA Settings → 「套用更新」
```
