## Fix

- **Windows helper 真 detach**:`Bun.spawn(["powershell.exe", ...], { detached:true })` 在 Windows 上**不真 detach**,backend `process.exit(0)` 1.5s 後 helper 一起被殺,從沒寫 `[helper]` log → swap / spawn 全沒做,新 backend 永遠起不來。改 `cmd.exe /c start "" /B powershell.exe ...`,start 是 cmd 內建的真 detach 工具,/B 不開 console window。Pattern 跟 helper 內 spawn 新 backend 那段相同,實證可用
