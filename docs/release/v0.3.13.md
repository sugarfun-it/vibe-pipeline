## Highlights
- **`vbpl pipeline run <id> --wait` 對新建的 pipeline 不再卡住不動** — 之前對還沒啟動(planning)的 pipeline 下 `--wait`,會誤判成「已經在跑了,我等就好」→ 結果根本沒幫你啟動、就一直空等到逾時。現在會正常啟動再等它跑完。

## Fix
`run --wait` 有個「已經在進行中就不重複觸發、直接等終態」的判斷,但把「建好還沒啟動(planning)」也算進了「進行中」，於是對新 pipeline 下 `--wait` 會跳過啟動那一步、空等到逾時。修正：planning 不算進行中，會正常送出啟動再等。
