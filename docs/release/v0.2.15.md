## Highlights
- **跑 pipeline 更穩,不會再卡在「執行中」或狀態對不上** — 跑到一半不會莫名卡死或顯示沒在跑。
- **執行 / 審核 / 合併 可各自選 provider 跟 model** — 例如執行用 Claude、審核用 Codex,混搭都行。

## Fix
以前 pipeline 的調度交給一個 AI 在帶,它偶爾自己出錯害整條卡住,或「明明改了卻顯示沒在跑」。這版把調度改成程式直接做(執行 AI、審核 AI 照舊),跑起來更穩、狀態更準。設定頁也清掉用不到的「主 Agent」欄,並讓執行 / 審核 / 合併各角色能分別挑 provider 跟 model。
