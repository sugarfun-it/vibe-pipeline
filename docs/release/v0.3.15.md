## Highlights
- **ticket 沒交付進 branch 時，原因講得更清楚** — 之前只說「worktree 沒改動」，現在會列出三種可能,第一條就是「產出被生成在 `.gitignore` 的資料夾(例如生成的圖)→ 不會進 branch，要把那個資料夾移出 .gitignore」，讓你一眼知道是設定問題不是 AI 沒做事。

## Fix
接續上一版的「空產出絆線」：當一張 ticket 跑完 worktree 沒有可提交的改動而暫停時，訊息改成列出三種成因 —— 產出落在 gitignored 路徑 / 跑去 worktree 外動手 / 真的沒做 —— 對應各自的修法，不用再猜。
