## Self-update — install-script-only(2 個入口共用 single source of truth)

走「install script 自包含」單一 path。後端只 spawn install script(detached + graceful socket close),install script 一條 path 包辦 stop → download → swap → start。

```
~/.vibe-pipeline/versions/v0.X.Y/   各版本獨立目錄(stripped package.json + 預裝 node_modules)
~/.vibe-pipeline/current → ...      junction(Win)/ symlink(POSIX)
~/.vibe-pipeline/bin/vbpl[.cmd]     shim,讀 current/cli/vbpl.ts
~/.vibe-pipeline/scripts/           install / uninstall scripts(ship 進 tarball)
```

兩個入口共用:

```bash
# Entry 1 — terminal user
vbpl update                                      # 任一平台

# Entry 2 — PWA / 沒 terminal
# Settings → 更新 → 「套用更新」按鈕 → backend POST /api/system/update

# Entry 3 — 一行裝
irm ...install.ps1 | iex                         # Windows
curl -fsSL ...install.sh | sh                    # macOS / Linux
```

PWA 一鍵 flow:
1. backend preflight + `await server.stop(true)`(close listening socket → 釋放 handle)
2. spawn `cmd /c start "" /B update-launcher.cmd`(真 detach)
3. launcher 跑 `powershell -File install.ps1 -AutoStart >> update.log 2>&1`
4. backend `process.exit(0)`,install 跑獨立
5. install:stop / Move-Item old / extract / bun install(verify) / swap junction
6. install 末段 `vbpl server start` Start-Process Hidden(新 backend 起在 default port)
7. PWA poll `/api/health` 直到 200,顯「✓ backend 已更新到 vX.Y.Z」

設計信條對齊:
- 「分開工作,不要 cross-process hook」— install script 自包含,沒 `.pending` 便條
- 雷 #15「server lifecycle = user-driven first class」— `vbpl server start` / install script 同 mental model
- 信條 6「ground truth 由 backend 驗」

## Windows-specific 修法(整套 e2e 通)

從研發 PWA 按鈕 e2e 路上踩過 10 個 Windows 雷,全 fix:

1. tarball 缺 scripts/ → 白名單補,enduser install dir 有 local install script
2. `irm | iex` 不接 args → fallback 改 temp download + 顯式 args
3. `Bun.spawn(stdio:fd, detached:true)` Windows 沒 launch install → 改 `cmd /c start "" /B launcher.cmd` 模式
4. install.ps1 step 5 rm 撞 file lock(backend module memory-mapped handle 釋放慢)→ Move-Item rename 到 `.bak-<random>` + 背景 cleanup
5. install.ps1 step 10 auto-start `Start-Process -Wait` 卡 caller → fire-and-forget + 內部 poll `/api/health`
6. backend `process.exit` Bun.serve socket 沒釋放 → `await server.stop(true)` graceful close
7. install 後代繼承 backend listening socket handle → port zombie → reorder「先 server.stop 再 spawn install」
8. install.ps1 自己 cwd 落 current/ 內 → step 7 移 current junction 撞自己 cwd lock → `Set-Location $VpHome` 在頂 + backend spawn cmd 時 `cwd: vpRoot()`
9. cmd /c start /B launcher.cmd 仍跳 console window → 改 **VBScript launcher**(`WScript.Shell.Run cmd, 0, False`,SW_HIDE)真 invisible
10. UpdateTab done msg 過囉嗦 → `✓ 已更新到 vX.Y.Z`
