## Self-update 整套重寫(Scoop-style)

舊版 `git pull + bun install + bun run build` 對 enduser 用不到(沒 `.git/`)。改成 versioned + indirection pattern(Squirrel / Scoop / pnpm 路線):

```
~/.vibe-pipeline/versions/v0.X.Y/   各版本獨立目錄
~/.vibe-pipeline/current → ...      junction(Win)/ symlink(POSIX)
~/.vibe-pipeline/.pending           純文字 tag,vbpl server start 偵測後 swap
```

Update flow:backend download + bun install 寫到 `versions/<tag>.staging/` → 寫 `.pending` → backend self-exit。User `vbpl server start` 偵測 `.pending` → promote staging → swap junction → spawn 新 backend。Swap 發生時 cwd 裡沒人,完全避開 Windows EBUSY / detach 雷。

## 一行裝完

```sh
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/eric14304/vibe-pipeline/main/scripts/install.sh | sh

# Windows PowerShell
irm https://raw.githubusercontent.com/eric14304/vibe-pipeline/main/scripts/install.ps1 | iex
```

抓 latest release tarball → 解到 `~/.vibe-pipeline/versions/v0.X.Y/` → 建 `current` junction/symlink → 寫 shim → 問是否加 PATH → 自動 `vbpl server start`。`uninstall.sh` / `uninstall.ps1` 對稱。

## CLI

- `vbpl --version` / `-v` 印當前版本
- `vbpl server start` 偵測 `.pending` 自動 swap 套用更新

## Fix

- push gateway `gatewayUrl()` 加 `DEFAULT_GATEWAY_URL` fallback,enduser 沒設 `PUSH_GATEWAY_URL` env 也能 auto-issue token
- `getCurrentVersion()` 加 fallback 讀 cwd `package.json version`(installed mode = 沒 `.git/`),不再永遠回 `dev-unknown`

## Maintainer 發 release

```bash
# bump package.json version 後
bun run scripts/build-tarball.ts v0.X.Y    # 嚴格白名單組 tarball
git tag v0.X.Y && git push --tags
gh release create v0.X.Y --notes-file docs/release/v0.X.Y.md vibe-pipeline-v0.X.Y.tar.gz
```
