## Highlights

- **Backend collapse**:單 process `:3001` serve API + PWA frontend(static + SPA fallback)。`vbpl server start` 一條指令就開好,不再需要 vite preview 中介。
- **Self-update flow 完整落地**:一行裝(`irm ... | iex` / `curl ... | sh`)、`vbpl update` CLI、PWA Settings「套用更新」。
- **Tarball 99% 瘦身**:預裝 stripped node_modules,enduser `bun install` 30-60s → <2s。tarball 823KB。
- **重構大瘦身**:3 條主檔(projects routes / SettingsPopover / FocusColumn)從 1100/950/1460 行 → 890/180/120。
