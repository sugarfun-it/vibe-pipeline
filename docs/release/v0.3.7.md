## Highlights
- **更新時 GitHub 抽風不會再害你斷線** — 之前安裝程式會「先關掉舊版、才去抓新版資訊」,抓不到就中止,結果你連舊版都沒得用、整個服務掛掉。現在改成「先確認抓得到新版、才關舊版」,而且抓不到時會自動換另一條路再試。

## Fix
更新流程把停止後端排在抓取新版資訊之前 —— GitHub 那個查詢偶爾會 504 失敗，於是後端已經被關掉、安裝又中止，留下一個起不來的空檔。現在順序反過來：先抓到新版（單一查詢失敗會自動改查清單），下載完成後才停舊後端，任何網路抽風都不會再讓你卡在沒有後端的狀態。

## 升級
```bash
vbpl update
# 或 PWA Settings → 「套用更新」
```
