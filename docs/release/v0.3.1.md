## Highlights
- **修了 Windows 上用 Codex 跑 ticket 會被權限擋住的問題** — 執行 / 審核 AI 設成 Codex 時,指令、HOME 路徑、pnpm 會被沙箱擋到驗收一直跑不過;現在恢復正常。

## Fix
v0.3.0 起執行/審核 AI 改成各自獨立啟動,Codex 在 Windows 上被套了過嚴的沙箱,把常規指令(Get-ChildItem、git 等)、家目錄與暫存目錄(pnpm 安裝處)全擋掉,導致 ticket 程式其實寫好了、驗收卻永遠失敗。這版在 Windows 放行 Codex 全權限(對齊舊版行為),macOS / Linux 維持沙箱。
