## Fix

- **update-helper.ps1 spawn 失敗 silent**:Windows PowerShell `Start-Process -RedirectStandardOutput X -RedirectStandardError Y` 不允許 X = Y(同檔),throw `InvalidOperationException` 被 try/catch 吃掉但仍 log `spawn ok`(誤報 ground truth)。改用 `cmd.exe /c bun run ... >> server.log 2>&1` 內建 redirect 合一檔
- **helper 缺 `bun install`**:tarball asset 不含 `node_modules/`(maintainer release whitelist 故意排除),helper 解壓蓋過 `app/` 後直接 spawn → 新 backend module not found。helper 在 rename 後、spawn 前同步跑 `bun install --silent`(Win/POSIX 兩條 path 都補)
- helper exception 訊息誠實化:不再寫死 `spawn ok`,改 `spawn invoked, can't confirm exit — check server.log`(背景 cmd.exe 真實退出無法同步取)
