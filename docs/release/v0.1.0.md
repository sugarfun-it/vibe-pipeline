# v0.1.0

Multi-AI agent pipeline orchestrator。每張 ticket 由執行 AI 跑、審核 AI 判,序列推進到驗收通過。

## Core

- Pipeline / Ticket 二層結構,iter 模式 critic FAIL 反覆迴圈到通過
- 每條 pipeline 跑在獨立 `git branch` + worktree,N 條平行不撞
- 6 task class 各自配 model / effort:`qa` / `split` / `runner` / `executor` / `critic` / `merge`
- Claude(訂閱 + API key)+ OpenAI Codex(`gpt-5.x`)雙 provider
- Stop = SIGKILL + `taskkill /T` 殺整棵 process tree,無 graceful 中介態
- 重置 pipeline:刪 worktree + 刪 branch + tickets 回 draft 一氣呵成

## CLI(`vbpl`)

- `project / pipeline / ticket / config / server` noun × verb
- `bun build --compile` binary,~50ms 啟動
- import `server/lib/*` 直存 fs,不發 HTTP,離線可用

## Web UI

- Board / Focus 雙欄,即時顯 ticket 進度 + worktree diff chip + base 落後 chip
- QA Drawer:AI 對話建 5 欄 ticket spec(goal / acceptance / mode / prompt / 等)
- Settings 6 task class 模型獨立配 + push event 開關
- PWA 可裝(Android / iOS 16.4+)

## Merge / Sync

- `git merge --no-ff` 先試秒級,衝突才升 AI 解
- AutoMerge 開關:pipeline ready 自動 merge,衝突 FCM push「AI 接手解衝突」
- Sync 把 base 同步進 pipeline branch,衝突走 modal 由 user 決定要不要 AI
- 成功判定看 git 三條件:`!MERGE_HEAD && !conflictMarkers && behindBaseCount===0`(不信 AI stdout)

## Push 通知

- FCM Push Gateway 部署 Cloud Run asia-east1,enduser 零設定
- Token lazy 自動 issue,IP rate limit 5/UTC day
- Backend 拔 firebase-admin,POST gateway HTTP

## 遠端存取

## 自我更新

- Settings「更新」tab 一鍵 check + 套用
- Backend `git pull` + `bun install` + `bun run build` + 重啟,失敗 log 回滾
- SwUpdateBanner 自動偵測新 bundle

## 跨平台

- Windows / macOS(Apple Silicon / Intel)/ Linux
- killProcessTree 雙路徑:Windows `taskkill /T`,POSIX `process.kill(-pid)`

## Performance

- Mount-time backend git spawn 為 0(metadata endpoint 純 fs,git lazy fetch)
- Polling 用 self-rescheduling `setTimeout`,Chrome tab freeze 不 catch-up burst
- useApi 300ms dedupe 避 visibility + focus 雙觸發
- SW first-install 不 force reload(避所有 component 二度 mount)
