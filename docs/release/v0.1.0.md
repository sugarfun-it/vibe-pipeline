## v0.1.0 — 初始版本

Multi-AI 編排器。一張 ticket 給「執行 AI + 審核 AI」一輪一輪跑到審核 pass,N 條 pipeline 平行各自跑在獨立 git branch + worktree。

## 你能拿來幹嘛

- 用 QA Drawer 跟 AI 對話建 ticket(目標 / 驗收 / mode / prompt)
- 一個 pipeline 多張 ticket 排隊跑,iter 模式自動迴圈到審核通過
- N 條 pipeline 平行不互撞(各自 git branch + worktree)
- pipeline ready 可自動 merge 回 base,衝突可丟給 AI 解
- FCM 推播到手機(PWA 裝 iOS 16.4+ / Android)
- Tailscale 走 HTTPS 從手機連回家裡 backend

## 設定

6 種 task 各配自己的 model / effort:`qa` / `split` / `runner` / `executor` / `critic` / `merge`。
Claude(訂閱 + API key)+ Codex(`gpt-5.x`)兩家可選。

## 平台

Windows / macOS(Apple Silicon / Intel)/ Linux。Bun 1.3+ · git(支援 worktree 的版本)。

安裝步驟看 [README](../../README.md)。
