## Highlights
- **更新完那個背景視窗會自己關掉，不再卡很久** — 之前安裝程式在「啟動後端」那步最久會卡 90 秒才關，其實後端早就起來了。現在最多確認 20 秒、好了就馬上關，沒等到也直接關（後端在背景照樣起得來）。

## Fix
安裝最後一步會自己等後端健康檢查最多 90 秒，後端明明已經在另一個程序裡正常啟動，視窗卻還吊著像當掉。改成短確認：後端一通就立刻關窗，逾時也不再顯誤導的錯誤、只說「背景啟動中」，因為負責啟動的程序會自己等到好為止。

（注意：這次更新跑的還是舊版安裝程式、視窗仍會卡一下；裝上 v0.3.9 之後才生效。）

## 升級
```bash
vbpl update
# 或 PWA Settings → 「套用更新」
```
