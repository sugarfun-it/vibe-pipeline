## Fix

- **tar extract 真修**:v0.1.4 加 `--force-local` 是基於錯誤前提(以為 git-for-Windows tar 是 GNU tar)。實測 git-for-Windows tar 是 **bsdtar (MSYS)** 不認 `--force-local` 直接 exit 1,System32 也是 bsdtar 同樣不認。真 root cause 是 git-for-Windows bsdtar 做 MSYS path 轉譯把 `C:\path` mangle 成 `C\:\\path`。修法:Windows 顯式呼叫 `%WINDIR%\System32\tar.exe`(Win10 17063+ 內建 native bsdtar,不做 MSYS mangling)。`server/lib/updater.ts:extractArchive` 跟 `install.ps1` 兩處都改。POSIX 仍走 PATH 上 `tar`(GNU tar 行為正常)
