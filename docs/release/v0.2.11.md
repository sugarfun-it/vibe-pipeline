## Highlights
- **pipeline 可以「跑到結束才回報」了** — `vbpl pipeline run <id> --wait` 會一直等到 pipeline 真的跑完(或停下)才回應,讓 AI 啟動後能等到結果再接著做,不用一直回頭問「跑完了沒」。

## Feature
以前啟動 pipeline 是「按下去就回」,AI 不會知道後來成功還是失敗。加了 `--wait` 後它會等到終態才回手:成功(ready / merged)、要你介入(paused)、失敗(failed)各自回不同結果。可搭 `--timeout` 設最長等待、`--poll` 設多久看一次。不加 `--wait` 維持原本「啟動就回」的行為。
