## Breaking

- **Self-update 改 Scoop-style versioned + swap-on-start**(v3 重寫)。前 2 版 launcher-script pattern 在 Windows 撞 8 個雷(detach 不靈 / PowerShell ANSI / tar mangling / `Start-Process` redirect / EBUSY 自殺 cwd...),改成主流長駐工具普遍走的 versioned-dir + indirection。新 layout:

  ```
  ~/.vibe-pipeline/versions/v0.1.X/   各版本獨立目錄
  ~/.vibe-pipeline/current → versions/...   junction(Win)/ symlink(POSIX)
  ~/.vibe-pipeline/.pending           純文字 tag,vbpl server start 偵測後 swap
  ```

  Update flow:backend 下載 + bun install 寫到 `versions/<tag>.staging/`(獨立目錄,**完全不碰 current/**)→ 寫 `.pending` → backend self-exit。User 跑 `vbpl server start`:CLI 偵測 `.pending` → promote staging → swap junction → spawn 新 backend from `current/`。Swap 發生時 cwd 裡沒人,Windows EBUSY 雷消失。

- **install.ps1 / install.sh** 改新 layout(versions/ + current junction/symlink + shim 指 current/)。舊 `~/.vibe-pipeline/app/` 自動 move 到 `app.legacy.bak/`(safe to delete)。
