## Highlights
- **執行 AI 沒把 ticket 目標做到不會自己收手** — 注入內建的 `/goal` 指令,把「ticket 目標達成前不要停」變成硬性條件:每輪結束會自動檢查目標達成沒,沒到就繼續做,治「做一半就交差 / 早退」。

## Feature
executor 的指令最前面自動帶上 `/goal <ticket 目標>`（Claude Code / Codex 內建指令）。它會掛一個 session 條件:目標沒達成前不讓這輪結束、自動再跑。配合先前的「空產出絆線」是雙保險 —— `/goal` 讓它當下別半途停,絆線在它真的沒產出時擋住。

需要 Claude Code v2.1.139 以上(較舊版本或關閉 hooks 的環境會略過,不影響其他功能)。
