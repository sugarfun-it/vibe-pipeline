## Fix

- **`tar` extract 在 Windows 100% 失敗**:`Bun.spawn(["tar",...])` 從 backend 內呼,Windows PATH 上有 git-for-Windows 的 GNU tar(usr/bin)時抓到的是 GNU tar 而非 System32 bsdtar,GNU tar 把 `C:\path` 當 SSH `host:path` 拒連,exit 128。任何裝 git 的 Windows enduser update flow 全炸(extract 階段就死,launcher helper 從沒被寫出)。修法:tar 加 `--force-local`(bsdtar / GNU tar 都接受,告訴 GNU tar 不要當網路 path 解析)。`updater.ts:extractArchive` 跟 `install.ps1` 兩處 tar 都補
