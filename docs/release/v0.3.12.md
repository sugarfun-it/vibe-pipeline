## Highlights
- **「清理已合併 worktree」改成「刪除已合併 pipeline」,一鍵把已合併的整條清乾淨** — 之前只清 worktree 資料夾、卡片還留在列表;現在連 worktree + branch + 紀錄一起刪,列表真的清爽。執行中的會自動跳過。

## Fix
舊的「清理已合併 worktree」只刪磁碟上的 worktree,已合併的 pipeline 卡片仍堆在列表裡,清了等於沒清的感覺。改成「刪除已合併 pipeline」：把所有已合併的 pipeline 連 worktree、branch、紀錄一次刪掉。程式碼都已經在主分支裡、刪除安全；但該 pipeline 在 App 內的 spec / 對話 / 驗收歷史會一起消失，確認框會先列出要刪哪些。
