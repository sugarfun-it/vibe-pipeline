## Highlights
- **pipeline 不會再「悄悄漏掉一張 ticket 的成果」** — 之前 worktree 沒帶到 `.env` 之類的檔,執行 AI 為了跑驗證會跑去主專案資料夾動手,結果那張 ticket 的 code 沒進 branch、卻被當成完成。現在兩道一起補:worktree 建立時自動帶齊機密/設定檔;就算還是沒在 worktree 留下東西,也會大聲停下來而不是假裝完成。

## Fix
1. **worktree 自動帶 gitignored 設定檔** — 建 worktree 時自動鏡像 `.env`、憑證、本地 config(跳過 `node_modules` / `dist` 這類大目錄),不用再手動填 `.worktreeinclude`。讓 worktree 本身就能跑驗證，執行 AI 沒理由跑去主資料夾。
2. **空產出絆線** — 一張 ticket 跑完，若 worktree 裡沒有任何可提交的改動，直接判失敗並暫停（附原因），不再標成「完成」。把以前的「靜默丟工作」變成「明顯停下找你」。

已 init 的專案下次跑新 pipeline 就自動生效，不用重 init。
