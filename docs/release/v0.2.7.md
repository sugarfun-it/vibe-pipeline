## Highlights

- **一行裝 + 一鍵升級** — Windows / Mac / Linux 各 1 行 install,之後走 CLI `vbpl update` 或 PWA Settings → 「立即更新」。升級流程修了一連串雷:Windows 從 PWA 按更新真的會動(改走 Task Scheduler)、不再卡 spinner、Windows 不再亂噴 timeout ERROR。
- **推播會收到了** — v0.2.0 推播壞,v0.2.1 起修好,別停在 v0.2.0。
- **UI 整體改順** — 按鈕 / 邊框 / drawer 邊角統一節奏,ticket 的「目標」「驗收」改成 markdown 渲染(bullet / code 不再糊在一起),diff / sync 按鈕一看就知道可點,mobile drawer 全螢幕不被 tab 擋。
- **Windows 上 `vbpl` 更穩** — 換成原生 `vbpl.exe`(從 Node / Bun script spawn 不再撞 ENOENT)、port 3001 被占用自動換、ticket / pipeline 寫檔 retry 拉長(防 fs.watch / 防毒密集時 EPERM 偶發掉資料)。
- **CLI 多了給 agent 用的 bulk 輸入** — `vbpl ticket add/update` 加 `--input-json <path|->` heredoc(一次塞 title / goal / prompt / acceptance,markdown 含 backtick / `$` / `!` 全安全),也支援 `--goal-file` / `--prompt-file` / `--acceptance-file` 走 path 或 stdin。
- **MIT license** — 開放 fork / 改 / 商用。

## port 被換的話 Tailscale 怎麼辦

backend 啟動撞 `EADDRINUSE` 會自動換 port,實際 port 寫在 `~/.vibe-pipeline/server.json`。Tailscale forward 要重新指:

```bash
tailscale serve --bg --https=443 http://localhost:<server.json 內的 port>
```

PWA / CLI 都自己讀 `server.json`,不必改。
