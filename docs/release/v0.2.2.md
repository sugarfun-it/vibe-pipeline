## Highlights

- **GitHub repo 搬到 `sugarfun-it` org** — install / update URL 全改新 org(舊 URL 走 GitHub auto-redirect)。
- **Windows PWA 觸發更新終於 work** — 改走 `schtasks`,Bun job KILL_ON_CLOSE 不再卡死 mediator。
- **死碼大掃** — 4 條並行 self-dogfood pipeline 砍超過 1200 行純死碼(backend / frontend / scripts / docs)。

## Fix

### Windows updater 改 `schtasks`

Bun 1.3.13 把 `Bun.spawn(detached, unref)` 的 child 丟進 `KILL_ON_JOB_CLOSE` job object,backend exit 時連坐殺死 install mediator。改用 `schtasks` 把 task 交給 Task Scheduler service(在 backend job 外執行)— 跟 Chrome / Edge / VS / Adobe updater 同套模式。

- `server/lib/updater.ts`:`Bun.spawn` mediator → `schtasks /create + /run`,task 名 `VibePipelineUpdate`
- `scripts/install.ps1`:`Start-Transcript` 寫 `update.log`、末段自清 task

舊版 enduser PWA 觸發無效,必須走 `vbpl update` CLI。升到 v0.2.2 後 PWA 路徑修好。
